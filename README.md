Types of kernels:

Kernel type              Description                                                     Examples OS
1.Monolithic             Singlr larg program, faster but difficult to modufy             Linux,Unix
2.Microkernel            Minimalist Design,only essential funtions run in kernel mode    QNX,Minix
3.Hybrid Kernel          Combination of Monolithic and Microkernel                       Windows, macOS
4.Exokernel              Give direct hardware access to applications                Experometal OS designs
