===========
1. Overview
===========

The UIOX kernel targets four processor families: ARMv7-A (arm32), ARMv8-A/AArch64 (arm64), AMD64/Intel 64 (x86-64), and RISC-V (RV32I/RV64I). Each architecture is implemented under 10_Arch/ with dedicated arch_init.c, arch_defs.h, memory, exception, and decode layers.

This document provides a reference for the instruction set of each architecture as used within the UIOX codebase — covering general-purpose instructions, system/privileged instructions, inline-assembly patterns, and UIOX-specific integration notes for the security BSP, memory management, and interrupt handling.

+--------------+-------------------------+----------------+-----------+--------+
| Architecture | Variant                 | UIOX Module    | Word Size | Endian |
+==============+=========================+================+===========+========+
| ARM32        | ARMv7-A                 | 10_Arch/arm32  | 32-bit    | Little |
+--------------+-------------------------+----------------+-----------+--------+
| ARM64        | ARMv8-A / AArch64       | 10_Arch/arm64  | 64-bit    | Little |
+--------------+-------------------------+----------------+-----------+--------+
| x86-64       | AMD64 / Intel 64        | 10_Arch/x86_64 | 64-bit    | Little |
+--------------+-------------------------+----------------+-----------+--------+
| RISC-V       | RV32I / RV64I + M/A/F/D | 10_Arch/riscv  | 32/64-bit | Little |
+--------------+-------------------------+----------------+-----------+--------+

==================
2. ARM32 (ARMv7-A)
==================

2.1  Register File
------------------

ARMv7-A provides 16 general-purpose 32-bit registers (R0–R15). Several banked register sets swap in automatically on exception entry.

+----------+----------+------------------------------------------------+
| Register | ABI Name | Role                                           |
+==========+==========+================================================+
| R0-R3    | a1-a4    | Argument / return value registers              |
+----------+----------+------------------------------------------------+
| R4-R11   | v1-v8    | Callee-saved variable registers                |
+----------+----------+------------------------------------------------+
| R11      | fp       | Frame pointer (optional, by convention)        |
+----------+----------+------------------------------------------------+
| R12      | ip       | Intra-procedure scratch (linker veneer)        |
+----------+----------+------------------------------------------------+
| R13      | sp       | Stack pointer                                  |
+----------+----------+------------------------------------------------+
| R14      | lr       | Link register — return address from BL/BLX     |
+----------+----------+------------------------------------------------+
| R15      | pc       | Program counter (readable/writable)            |
+----------+----------+------------------------------------------------+
| CPSR     | —        | Current Program Status Register (flags + mode) |
+----------+----------+------------------------------------------------+
| SPSR     | —        | Saved PSR — holds pre-exception CPSR           |
+----------+----------+------------------------------------------------+

2.2  Processor Modes
--------------------

ARMv7-A implements eight processor modes. UIOX runs the kernel in Supervisor (SVC) mode.

+------------+----------+------------------------------------------+
| Mode       | Encoding | Purpose                                  |
+============+==========+==========================================+
| User       | 0b10000  | Unprivileged task execution              |
+------------+----------+------------------------------------------+
| FIQ        | 0b10001  | Fast interrupt — has R8-R14 banked       |
+------------+----------+------------------------------------------+
| IRQ        | 0b10010  | Normal interrupt                         |
+------------+----------+------------------------------------------+
| Supervisor | 0b10011  | Kernel / SVC call handler (UIOX default) |
+------------+----------+------------------------------------------+
| Monitor    | 0b10110  | TrustZone Secure Monitor (SMC)           |
+------------+----------+------------------------------------------+
| Abort      | 0b10111  | Prefetch / data abort handler            |
+------------+----------+------------------------------------------+
| Undefined  | 0b11011  | Undefined instruction handler            |
+------------+----------+------------------------------------------+
| System     | 0b11111  | Privileged, shares User register bank    |
+------------+----------+------------------------------------------+

2.3  Core Instruction Set
-------------------------

2.3.1  Data Processing
~~~~~~~~~~~~~~~~~~~~~~

Format: ``<opcode>{S}{cond} Rd, Rn, operand2``. The ``S`` suffix updates CPSR flags.

+-------------+-----------------------+------------------------------+---------+
| Instruction | Syntax                | Operation                    | Flags   |
+=============+=======================+==============================+=========+
| MOV         | MOV Rd, op2           | Rd = op2                     | N,Z,C   |
+-------------+-----------------------+------------------------------+---------+
| MVN         | MVN Rd, op2           | Rd = ~op2                    | N,Z,C   |
+-------------+-----------------------+------------------------------+---------+
| ADD         | ADD Rd, Rn, op2       | Rd = Rn + op2                | N,Z,C,V |
+-------------+-----------------------+------------------------------+---------+
| ADC         | ADC Rd, Rn, op2       | Rd = Rn + op2 + C            | N,Z,C,V |
+-------------+-----------------------+------------------------------+---------+
| SUB         | SUB Rd, Rn, op2       | Rd = Rn - op2                | N,Z,C,V |
+-------------+-----------------------+------------------------------+---------+
| SBC         | SBC Rd, Rn, op2       | Rd = Rn - op2 - ~C           | N,Z,C,V |
+-------------+-----------------------+------------------------------+---------+
| RSB         | RSB Rd, Rn, op2       | Rd = op2 - Rn                | N,Z,C,V |
+-------------+-----------------------+------------------------------+---------+
| AND         | AND Rd, Rn, op2       | Rd = Rn & op2                | N,Z,C   |
+-------------+-----------------------+------------------------------+---------+
| ORR         | ORR Rd, Rn, op2       | Rd = Rn | op2                | N,Z,C   |
+-------------+-----------------------+------------------------------+---------+
| EOR         | EOR Rd, Rn, op2       | Rd = Rn ^ op2                | N,Z,C   |
+-------------+-----------------------+------------------------------+---------+
| BIC         | BIC Rd, Rn, op2       | Rd = Rn & ~op2               | N,Z,C   |
+-------------+-----------------------+------------------------------+---------+
| CMP         | CMP Rn, op2           | flags on Rn - op2            | N,Z,C,V |
+-------------+-----------------------+------------------------------+---------+
| TST         | TST Rn, op2           | flags on Rn & op2            | N,Z,C   |
+-------------+-----------------------+------------------------------+---------+
| MUL         | MUL Rd, Rm, Rs        | Rd = Rm * Rs (low 32)        | N,Z     |
+-------------+-----------------------+------------------------------+---------+
| MLA         | MLA Rd, Rm, Rs, Rn    | Rd = Rm * Rs + Rn            | N,Z     |
+-------------+-----------------------+------------------------------+---------+
| UMULL       | UMULL RdLo,RdHi,Rm,Rs | RdHi:RdLo = Rm * Rs (64-bit) | N,Z     |
+-------------+-----------------------+------------------------------+---------+

2.3.2  Shift / Rotate (Operand2 Modifiers)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

+-----------------+------------------------------------------------+
| Modifier        | Meaning                                        |
+=================+================================================+
| LSL #n / LSL Rx | Logical shift left by n bits or contents of Rx |
+-----------------+------------------------------------------------+
| LSR #n / LSR Rx | Logical shift right (zero fill)                |
+-----------------+------------------------------------------------+
| ASR #n / ASR Rx | Arithmetic shift right (sign extend)           |
+-----------------+------------------------------------------------+
| ROR #n / ROR Rx | Rotate right                                   |
+-----------------+------------------------------------------------+
| RRX             | Rotate right one bit through carry             |
+-----------------+------------------------------------------------+

2.3.3  Load / Store
~~~~~~~~~~~~~~~~~~~

+-------------+--------------------------+-------------------------------------+
| Instruction | Syntax                   | Operation                           |
+=============+==========================+=====================================+
| LDR         | LDR Rt, [Rn, #off]       | Rt = Mem32[Rn+off]                  |
+-------------+--------------------------+-------------------------------------+
| STR         | STR Rt, [Rn, #off]       | Mem32[Rn+off] = Rt                  |
+-------------+--------------------------+-------------------------------------+
| LDRB        | LDRB Rt, [Rn, #off]      | Rt = zext(Mem8[Rn+off])             |
+-------------+--------------------------+-------------------------------------+
| STRB        | STRB Rt, [Rn, #off]      | Mem8[Rn+off] = Rt[7:0]              |
+-------------+--------------------------+-------------------------------------+
| LDRH        | LDRH Rt, [Rn, #off]      | Rt = zext(Mem16[Rn+off])            |
+-------------+--------------------------+-------------------------------------+
| STRH        | STRH Rt, [Rn, #off]      | Mem16[Rn+off] = Rt[15:0]            |
+-------------+--------------------------+-------------------------------------+
| LDRD        | LDRD Rt, Rt2, [Rn, #off] | Rt:Rt2 = Mem64[Rn+off]              |
+-------------+--------------------------+-------------------------------------+
| LDM         | LDM Rn, {reglist}        | Load multiple registers from [Rn]   |
+-------------+--------------------------+-------------------------------------+
| STM         | STM Rn, {reglist}        | Store multiple registers to [Rn]    |
+-------------+--------------------------+-------------------------------------+
| PUSH        | PUSH {reglist}           | STM SP!, {reglist} — push to stack  |
+-------------+--------------------------+-------------------------------------+
| POP         | POP {reglist}            | LDM SP!, {reglist} — pop from stack |
+-------------+--------------------------+-------------------------------------+

2.3.4  Branch
~~~~~~~~~~~~~

+-------------+--------------------------------------------------+
| Instruction | Operation                                        |
+=============+==================================================+
| B label     | PC = label (+-32 MB range)                       |
+-------------+--------------------------------------------------+
| BL label    | LR = PC+4; PC = label (subroutine call)          |
+-------------+--------------------------------------------------+
| BX Rm       | PC = Rm (bit[0]=1 => switch to Thumb)            |
+-------------+--------------------------------------------------+
| BLX Rm      | LR = PC+4; PC = Rm (call + possible mode switch) |
+-------------+--------------------------------------------------+
| BLX label   | Unconditional BL + Thumb/ARM switch              |
+-------------+--------------------------------------------------+
| CBZ Rn, lbl | Branch if Rn == 0 (Thumb-2 only)                 |
+-------------+--------------------------------------------------+
| CBNZ Rn,lbl | Branch if Rn != 0 (Thumb-2 only)                 |
+-------------+--------------------------------------------------+

2.3.5  System / Privileged
~~~~~~~~~~~~~~~~~~~~~~~~~~

+----------------------------+--------------------------------------------------------+
| Instruction                | Operation                                              |
+============================+========================================================+
| SWI / SVC #imm             | Supervisor Call => SVC exception => UIOX syscall entry |
+----------------------------+--------------------------------------------------------+
| SMC #imm                   | Secure Monitor Call => Monitor mode (TrustZone SMCCC)  |
+----------------------------+--------------------------------------------------------+
| MRS Rd, <sysreg>           | Read special register (CPSR, SPSR, CP15) into Rd       |
+----------------------------+--------------------------------------------------------+
| MSR <sysreg>, Rn           | Write Rn to special register                           |
+----------------------------+--------------------------------------------------------+
| MRC p15,op1,Rt,CRn,CRm,op2 | Read CP15 coprocessor register                         |
+----------------------------+--------------------------------------------------------+
| MCR p15,op1,Rt,CRn,CRm,op2 | Write CP15 coprocessor register                        |
+----------------------------+--------------------------------------------------------+
| MRRC p15,op,Rt,Rt2,CRm     | Read 64-bit CP15 register (e.g. CNTPCT)                |
+----------------------------+--------------------------------------------------------+
| ISB                        | Instruction Synchronisation Barrier                    |
+----------------------------+--------------------------------------------------------+
| DSB sy                     | Data Synchronisation Barrier — full system             |
+----------------------------+--------------------------------------------------------+
| DMB sy                     | Data Memory Barrier — ordering only                    |
+----------------------------+--------------------------------------------------------+
| CLREX                      | Clear exclusive monitor (after LDREX/STREX failure)    |
+----------------------------+--------------------------------------------------------+
| LDREX Rt, [Rn]             | Load-Exclusive 32-bit (begin atomic RMW)               |
+----------------------------+--------------------------------------------------------+
| STREX Rd, Rt, [Rn]         | Store-Exclusive — Rd=0 if succeeded                    |
+----------------------------+--------------------------------------------------------+
| WFI                        | Wait For Interrupt (low-power idle)                    |
+----------------------------+--------------------------------------------------------+
| WFE                        | Wait For Event                                         |
+----------------------------+--------------------------------------------------------+
| SEV                        | Send Event (wake WFE on other core)                    |
+----------------------------+--------------------------------------------------------+

2.4  UIOX ARM32 Inline Assembly Patterns
----------------------------------------

**GIC IRQ enable (CPSR I-bit clear):**

.. code-block:: asm

   __asm__ volatile("cpsie i" ::: "memory");

**Read cycle counter (PMCCNTR):**

.. code-block:: asm

   __asm__ volatile("mrc p15, 0, %0, c9, c13, 0" : "=r"(val));

**ARMv7 generic timer (CNTPCT 64-bit read):**

.. code-block:: asm

   __asm__ volatile("mrrc p15, 0, %0, %1, c14" : "=r"(lo), "=r"(hi));

**SP804 timer MMIO barrier after write:**

.. code-block:: asm

   __asm__ volatile("dsb sy" ::: "memory");

3. ARM64 (ARMv8-A / AArch64)
============================

3.1  Register File
------------------

AArch64 provides 31 general-purpose 64-bit registers (X0–X30) plus XZR and SP. Lower 32 bits accessed as W0–W30.

+----------+----------+----------------------------------------------+
| Register | ABI Name | Role                                         |
+==========+==========+==============================================+
| X0-X7    | arg/ret  | Arguments and return values (first 8)        |
+----------+----------+----------------------------------------------+
| X8       | indirect | Indirect result / syscall number (Linux ABI) |
+----------+----------+----------------------------------------------+
| X9-X15   | scratch  | Caller-saved temporaries                     |
+----------+----------+----------------------------------------------+
| X16-X17  | IP0-IP1  | Intra-procedure scratch (linker / PLT)       |
+----------+----------+----------------------------------------------+
| X18      | platform | Platform register (reserved on some ABIs)    |
+----------+----------+----------------------------------------------+
| X19-X28  | callee   | Callee-saved registers                       |
+----------+----------+----------------------------------------------+
| X29      | fp       | Frame pointer                                |
+----------+----------+----------------------------------------------+
| X30      | lr       | Link register (return address from BL)       |
+----------+----------+----------------------------------------------+
| SP       | sp       | Stack pointer (16-byte aligned in ABI)       |
+----------+----------+----------------------------------------------+
| XZR/WZR  | —        | Reads as 0; writes discarded                 |
+----------+----------+----------------------------------------------+
| NZCV     | —        | Condition flags (N,Z,C,V)                    |
+----------+----------+----------------------------------------------+
| DAIF     | —        | IRQ/FIQ/SError/Debug masks                   |
+----------+----------+----------------------------------------------+
| ELR_ELn  | —        | Exception Link Register (per EL)             |
+----------+----------+----------------------------------------------+
| SPSR_ELn | —        | Saved PSTATE (per EL)                        |
+----------+----------+----------------------------------------------+

3.2  Exception Levels
---------------------

+-------+----------------+--------------------------------------------------+
| Level | Name           | UIOX Role                                        |
+=======+================+==================================================+
| EL0   | User           | Unprivileged process / task execution            |
+-------+----------------+--------------------------------------------------+
| EL1   | Kernel         | UIOX kernel — interrupt handlers, MMU, scheduler |
+-------+----------------+--------------------------------------------------+
| EL2   | Hypervisor     | Optional VM host (not used in base UIOX)         |
+-------+----------------+--------------------------------------------------+
| EL3   | Secure Monitor | TrustZone firmware — SMC calls from UIOX BSP     |
+-------+----------------+--------------------------------------------------+

3.5  UIOX ARM64 Inline Assembly Patterns
----------------------------------------

**IRQ disable via DAIF:**

.. code-block:: asm

   __asm__ volatile("msr daifset, #2" ::: "memory");

**IRQ enable via DAIF:**

.. code-block:: asm

   __asm__ volatile("msr daifclr, #2" ::: "memory");

**Read RNDR with carry-check:**

.. code-block:: asm

   __asm__ volatile("mrs %0, rndr \n\t" "cset %w1, cs" : "=r"(val), "=r"(ok));

**SMCCC SMC64 call:**

.. code-block:: asm

   __asm__ volatile("smc #0" : "+r"(x0),"+r"(x1),"+r"(x2),"+r"(x3));

**TLB invalidate after page table update:**

.. code-block:: asm

   __asm__ volatile("dsb ishst \n\t" "tlbi vmalle1is \n\t" "dsb ish \n\t" "isb");

4. x86-64 (AMD64 / Intel 64)
============================

4.1  Register File
------------------

+----------+-------------------------------+-----------------------------------------------+
| Register | ABI Role                      | Notes                                         |
+==========+===============================+===============================================+

4.5  UIOX x86-64 Inline Assembly Patterns
-----------------------------------------

**RDRAND with retry:**

.. code-block:: asm

   __asm__ volatile("rdrand %0 \n\t" "setc %1" : "=r"(val), "=qm"(cf));

**RDSEED with PAUSE between retries:**

.. code-block:: asm

   __asm__ volatile("rdseed %0 \n\t" "setc %1" : "=r"(val), "=qm"(cf));

**RDTSC timestamp:**

.. code-block:: asm

   __asm__ volatile("rdtsc" : "=a"(lo), "=d"(hi));

**CPUID leaf 0x07:**

.. code-block:: asm

   __asm__ volatile("cpuid" : "=a"(*a),"=b"(*b),"=c"(*c),"=d"(*d) : "a"(7u),"c"(0u));

**Atomic CAS (LOCK CMPXCHG):**

.. code-block:: asm

   __asm__ volatile("lock; cmpxchgq %2,%1" : "=a"(old),"+m"(*ptr) : "r"(newval),"0"(old) : "cc");

**SWAPGS at syscall entry:**

.. code-block:: asm

   __asm__ volatile("swapgs" ::: "memory");

--------------------------

+-------------+--------------------+-----------------------------------------------------------------------------------------------------------+
| Instruction | Syntax             | Operation                                                                                                 |
+=============+====================+===========================================================================================================+
| FENCE       | FENCE pred, succ   | Order memory accesses: pred set before succ set. pred/succ = I/O/R/W combos. FENCE RW,RW is full barrier. |
+-------------+--------------------+-----------------------------------------------------------------------------------------------------------+

5.9  SBI (Supervisor Binary Interface) Calls

SBI calls use ``ECALL`` with ``a7`` = Extension ID, ``a6`` = Function ID, ``a0``–``a5`` as arguments.

| 0x01       | Legacy Console Putchar | Single-character console output                       |

| 0x10       | Base Extension         | sbi_get_spec_version, sbi_probe_extension             |

| 0x54494D45 | Timer (TIME)           | sbi_set_timer(stime_value) — UIOX timer interrupt     |
+------------+------------------------+-------------------------------------------------------+

5.10  UIOX RISC-V Inline Assembly Patterns
------------------------------------------

**Read time CSR (uiox_sec_plat_time_ms):**

.. code-block:: asm

   __asm__ volatile("rdtime %0" : "=r"(t));

**Read cycle counter:**

.. code-block:: asm

   __asm__ volatile("rdcycle %0" : "=r"(cycles));

**Full memory barrier:**

.. code-block:: asm

   __asm__ volatile("fence rw, rw" ::: "memory");

**I-cache fence:**

.. code-block:: asm

   __asm__ volatile("fence.i" ::: "memory");

**Disable S-mode interrupts:**

.. code-block:: asm

   __asm__ volatile("csrc sstatus, %0" :: "r"(0x2u) : "memory");

**Enable S-mode interrupts:**

.. code-block:: asm

   __asm__ volatile("csrs sstatus, %0" :: "r"(0x2u) : "memory");

**Read satp:**

.. code-block:: asm

   __asm__ volatile("csrr %0, satp" : "=r"(satp_val) :: "memory");

**Write satp + flush TLB:**

.. code-block:: asm

   __asm__ volatile("csrw satp, %0 \n\t" "sfence.vma" :: "r"(satp_val) : "memory");
